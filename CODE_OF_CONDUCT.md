# Code of Conduct

## Our commitment

We want StackOrbit to be a welcoming, respectful, and harassment-free project for everyone, regardless of experience, identity, background, or location.

## Expected behavior

- Be respectful and constructive.
- Assume good intent and ask questions before making assumptions.
- Focus criticism on ideas and code, never on people.
- Accept feedback and different technical perspectives.
- Protect private information and project credentials.

## Unacceptable behavior

Harassment, discrimination, intimidation, personal attacks, unwanted sexual attention, doxxing, threats, and deliberate disruption are not acceptable.

## Enforcement

Report concerns privately to the project maintainers through the security contact or private GitHub report. Reports will be reviewed fairly and confidentially. Maintainers may remove content, restrict participation, or take other action they consider appropriate.

This code of conduct is adapted from the Contributor Covenant.
